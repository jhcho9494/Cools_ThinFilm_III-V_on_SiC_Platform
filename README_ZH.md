# Cools 薄膜 III-V on SiC 光半导体平台

[English](README.md) | [한국어](README_KR.md) | [专利组合](PATENT_PORTFOLIO.md) | [公开声明](PUBLIC_NOTICE.md)

## III-V 负责光功能，SiC 承担其下方的热、应力、机械与封装

**仅在需要发光、调制、探测和波导功能的位置使用昂贵的磷化铟（InP）系 III-V 薄膜；由碳化硅（SiC）平台承担散热、机械支撑、热膨胀匹配、光学对准和封装功能。**

传统结构中，整片 InP 晶圆同时承担外延模板、光学功能层、机械支撑和导热路径。Cools 平台将这些功能分离：

```text
光器件 / 电极 / 光波导
────────────────────────
InP 系 III-V 光功能薄膜
(InP / InGaAs / InGaAsP / InAlGaAs / MQW / APD / SPAD)
────────────────────────
直接键合或超薄键合界面
────────────────────────
SiC 系散热·机械·封装平台
(单晶 SiC / 薄膜 SiC / 多晶 SiC / RBSC)
```

---

## 1. 平台结构

| 层级 | 主要作用 |
|---|---|
| InP 系 III-V 薄膜 | 发光、调制、探测、导波、多量子阱功能 |
| 键合界面 | 低温连接、低界面热阻、可选电学与界面调控 |
| SiC 系支撑层 | 热扩散、机械支撑、热膨胀匹配、封装基座、光学对准基准、垂直通孔平台 |

III-V 光功能薄膜并不限于纯 InP，也可包括 InGaAs、InGaAsP、InAlGaAs、多量子阱（MQW）、激光器外延堆叠、雪崩光电二极管（APD）和单光子雪崩二极管（SPAD）。

---

## 2. 为什么选择 SiC 作为永久支撑平台

### 高效散热

InP 的热导率约为 68 W/m·K，而高质量单晶 SiC 可达到约 490 W/m·K。激光器、调制器和探测器的热量可沿短路径迅速传入 SiC。

### 热膨胀匹配

SiC 与 InP 的热膨胀系数分别约为 4.0 ppm/K 和 4.6 ppm/K，明显优于 InP-on-Si 组合，可降低键合、冷却及热循环过程中的残余应力和薄膜裂纹。

### 机械与封装功能集成

SiC 支撑层可以同时作为：

- 高刚性封装基座，
- 热扩散器，
- 光学对准参考面，
- 垂直光互连平台，
- 光通孔或电通孔的承载基体。

## 3. 从消耗整片 InP 转向可重复使用供体

代表性流程如下：

```text
1. 准备 InP 系 III-V 供体或外延堆叠
2. 通过 H/He 离子注入形成埋置分离面
3. 与 SiC 系支撑层低温键合
4. 沿分离面剥离并转移 III-V 薄膜
5. 完成薄膜表面处理及光器件制造
6. 修复并重复使用剩余供体
```

每个循环仅消耗亚微米至数微米厚的功能层。根据转移厚度、供体表面恢复损耗和重复次数，目标是将 InP 原材料消耗降低到传统体基板方案的约 **1/100 至 1/300**。

## 4. 键合界面选择

平台不限定于单一键合工艺，可采用：

- 亲水直接键合，
- 等离子体活化键合，
- 氧化物或氮化物中间层键合，
- 金属键合，
- 苯并环丁烯（BCB）键合，
- 聚乙烯亚胺（PEI）或乙氧基化聚乙烯亚胺（PEIE）等含胺分子层键合。

关键目标是保持界面足够薄，避免厚胶层或焊料层抵消 SiC 的散热优势。

---

## 5. SiC 支撑层变体

### 单晶 SiC

适用于最高热导率、均匀后侧光入射和高可靠性场景。

### 其他载体上的薄膜 SiC

适用于与硅 CMOS 读出电路、垂直光互连和复合光学堆叠集成。

### 多晶 SiC

无需整片单晶晶圆即可获得高刚性和高导热支撑。

### 反应结合碳化硅（RBSC）

适用于大面积、低成本、高刚性散热平台。由于 RBSC 含有残余硅、孔隙和多相组织，其主要定位为热与机械平台；如需光入射，可设置开口、局部单晶 SiC 窗口、光通孔、侧面或正面照明路径。

---

## 6. 可选的局部光热后处理

光热处理是平台的可选扩展，而非核心结构的必要限定。

光可从正面、背面、侧面、光通孔或透明窗口入射，并由 III-V 薄膜内的选择吸收区域形成局部热峰。目标区域可包括：

- 多量子阱，
- 掺杂区和自由载流子吸收区，
- 离子注入损伤区及缺陷能级区，
- 埋置金属吸收层，
- 界面反应层，
- 专用光吸收辅助层。

该方法可用于缺陷恢复、掺杂激活、波长微调及局部量子阱混合，同时限制热影响区。

## 7. 应用平台

### 汽车激光雷达

可在同一 SiC 平台上集成 1,500–1,600 nm 光源和探测器，并扩展到飞行时间、调频连续波、相干探测和光学相控阵结构。

### 共封装光学

SiC 可作为光引擎散热手柄、光学对准基准、高刚性低膨胀封装基座，并支持与交换 ASIC 的近距离集成。

### SWIR 成像

可通过薄膜 SiC 中间层将 InGaAs/InP 探测堆叠转移到硅 CMOS 读出集成电路上，实现细像素、高均匀性的短波红外阵列。

### 量子光子学与量子密钥分发

可在热稳定 SiC 平台上集成 III-V 单光子源、SPAD 及可选石墨烯功能层。

### 空间多结太阳电池

由 SiC 支撑转移式 III-V 多结薄膜堆叠，可减少厚锗基板的使用；石墨烯、超薄金属网或其他透明导电层可进一步降低对氧化铟锡的依赖。

## 8. 本质差异

```text
传统：体 III-V 基板同时承担结构与功能

Cools：可重复使用的 III-V 供体仅提供功能薄膜
       + SiC 作为永久散热·机械·封装平台
```

因此，本平台并非简单地把 InP 芯片贴装到 SiC 散热片上，而是将永久基板从 III-V 转换为 SiC，仅保留 III-V 的光功能薄膜。
